# 减脂打卡｜本地网页版

这是一个不需要账号、服务器、IPA 或第三方 App 的本地减脂打卡网页。数据保存在当前浏览器的 `localStorage` 中。

## 电脑打开

直接双击 `index.html` 即可使用。若浏览器限制本地文件的部分能力，也可以在此文件夹运行任意静态服务器，例如：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。

## iPhone 使用

1. 把整个文件夹放到你能用 Safari 访问的位置；本地文件可通过“文件”App 打开，长期使用更建议放在你自己的静态网页托管空间。
2. 用 Safari 打开 `index.html` 或网页地址。
3. 点击分享按钮 → **添加到主屏幕**。
4. 以后从主屏幕图标打开，进入“今日”即可记录。

## 记录逻辑

- 新日期首次打开时，会根据星期填入计划参考；参考可以随时修改。
- 实际训练部位支持多选，也可以在自定义部位中填写临时安排；统计只看实际完成情况。
- 数据和计划可以在三个月之后继续使用，不会自动停止。
- 统计按本地时间和周一至周日计算，空白字段不会被当成 0 纳入平均值。

## 备份

进入“设置”→“导出备份”，保存 JSON 文件。换浏览器或清除网站数据前务必先导出。恢复时进入“设置”→“导入备份”选择 JSON 文件。

## 提醒说明

纯本地网页在 iPhone 完全关闭时不能可靠地发送后台系统通知。网页会保存提醒时间，并在打开网页且到达提醒时间时显示提示。需要稳定的每日提醒时，请同时在 iPhone 的“提醒事项”中建立每日提醒。

## 数据隐私

本项目没有网络请求、登录、统计代码或外部依赖。所有记录只保存在本机浏览器；清理浏览器网站数据可能删除记录。
